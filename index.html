About

No dependencies, no build step — plain Canvas 2D and ES modules. A face is a genome: a JSON object of traits derived from a seed. Store the seed, not the image.

Keyboard: f focus, c compare, k keep, r new seed, ← → step through. Downloads save a file when the page is served normally; some embedded viewers block them.

Four layers stack, general to specific: population → kin → archetype → pins. See README.md for the API, the atlas export and the Godot 4 loader.
